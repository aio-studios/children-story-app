# Hero Illustration per Story (#38 v1) — Implementation Plan

**Overall Progress:** `100%` — code complete, credentials provisioned, `/verify` passed end-to-end (real Gemini + Blob, all UI states light+dark at iPhone 12 Pro), reviews clean. Awaiting your UAT sign-off to close #38.

## TLDR
Add one optional AI-generated **cover image per story** to the reader. Opt-in via a toggle on the Customize step (**default OFF**). Story text renders immediately as today; if the toggle is on, the hero image is generated in a **separate, non-blocking call** and fills in after — with a graceful fallback if it fails. Image generated by **Gemini 2.5 Flash Image ("Nano Banana")** via the **Vercel AI SDK**, stored in **Vercel Blob**, and prompted from a **character sheet** derived from the existing validated selections so it matches the story's character. Scoped to one hero image so it's forward-compatible with #37's future per-scene illustrations. Approved design: [docs/designs/illustration-hero-preview.html](../docs/designs/illustration-hero-preview.html).

## Critical Decisions
- **One hero image, not per-scene** — today's story is a single text blob with no scene structure; "per scene" belongs to #37. A cover image ships the whole pipeline (vendor, toggle, storage, rendering) now and drops into per-scene later.
- **Separate `/api/generate-illustration` route** — keeps text non-blocking. Reader shows the story instantly; the image is a second fetch that never gates the story.
- **Vercel AI SDK + Gemini 2.5 Flash Image** — swappable provider behind one TS interface, built-in kid-safety filters + SynthID watermark, character-consistency-tuned, ~$0.04/image.
- **Vercel Blob storage** — provider bytes uploaded to Blob; the persistent public URL is what we store/render (so a resumed "Continue story" keeps its image without re-generating).
- **Toggle default OFF** — protects the budget on a public no-auth demo; cost only accrues on deliberate opt-in. Illustration route gets its own rate-limit bucket.
- **Server re-validates + re-safety-checks** — the illustration route re-runs `validateSelections` and the custom-text safety checks (not trusting the client), same as generate-story. Gemini's own filter is a backstop.
- **Character sheet from `selections`** — reuse the existing character/genre description, not a new client-supplied string, so consistency is forward-compatible with #37.
