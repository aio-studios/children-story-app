Navigation B, adapted to every screen

The chosen bottom-bar direction isn't one layout — it adapts: bottom bar on phone portrait, a compact icon rail in landscape, a full sidebar on iPad (where content also goes multi-column). Same nav model, same content, right shape for each device. Flip form factors and themes below.

The adaptive rule (one nav model, three shapes)

Form factorNav shapeWhyContent
Phone · PortraitBottom bar + center CreateThumb zone; the app's defaultSingle-column shelves
Phone · LandscapeCompact left icon railVertical space is scarce — a bottom bar would steal ~20% of height (#75)Shelves keep flowing; more per row

Breakpoint logic (for build): nav shape keys off available width + orientation — compact width & portrait → bottom bar; short height (landscape phone) → rail; ≥ tablet width → sidebar. Create is always one tap away in every shape.
